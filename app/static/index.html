Printer compatibility

Bed and toolhead geometry from the official OrcaSlicer 0.4 mm machine profiles. Only the Bambu Lab A1 is verified on hardware. All other models are marked needs a test print: watch the first cycle before going unattended. Prusa/Creality/Elegoo/Anycubic/QIDI/Sovol/Voron files must be sliced with OrcaSlicer — native PrusaSlicer .gcode/.bgcode is not supported yet.

Own one of these printers? Run the test protocol and submit a verification report. Every real test makes the compatibility data better.
