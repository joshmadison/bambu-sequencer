PlateLoop turns a sliced .gcode.3mf into one sequence file: print a copy, let the bed cool, push the part off with the printer's own toolhead, reheat, and start the next copy. No ejector, conveyor, or custom end effector.

The problem it solves

Printing many copies of the same small part usually means starting the printer again and again, waiting for each plate to cool, and clearing the bed by hand. A print farm either pays someone to babysit the machine or buys a robot arm, conveyor, or custom ejector.

Without PlateLoop

  • One plate, one print, then manual removal.
  • The printer sits idle while you clear the bed.
  • Batch jobs are limited by how long someone is available.
  • Automation hardware is expensive and printer-specific.

With PlateLoop

  • One file runs print → cool → push → reheat → next copy.
  • The printer's own toolhead pushes the part into a container.
  • Multiple copies and multiple plates run back to back.
  • No ejector, conveyor, or custom end effector.

It is not a robot. Parts must be sturdy and tall enough, bed adhesion must be reliable, and the first cycle must be supervised. Tall, thin, or fragile parts can jam; the app warns about known limits before building.

Why it works without extra hardware

The part is pushed by the printer's own toolhead. PlateLoop inserts the right moves between copies while preserving the printer's native start and end gcode.

  • Multi-plate files run back to back, with per-plate copy counts.
  • Multiple objects are pushed off one by one, rear-most first.
  • Safety checks cover minimum part height, cooling, and push-lane collisions.
  • Works with Bambu Studio and OrcaSlicer exports.

Private by design

No account, no cloud, no telemetry. Uploads are processed in memory and are not stored. The project is open source under the MIT license.

Own one of them? Run the test protocol and submit a verification report. A short written report is enough; video and photos are optional.

Safety first

PlateLoop changes the motion commands in the generated file. Never leave the printer unattended on the first full cycle for a new model or material.

  • Place a container at the front of the printer where the part lands.
  • Keep the push lane clear and check the rear clearance.
  • Use parts tall enough for the toolhead; the default minimum is 7 mm.
  • Watch the first print → cool → push → reheat cycle before relying on it.
